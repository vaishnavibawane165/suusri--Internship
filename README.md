# SuuSri AI Internship - Task Manager

Full-stack Task Manager app built during Week 1 of the SuuSri AI internship.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB

## How to Run
1. Clone this repository
2. Navigate to backend folder: `cd backend`
3. Install dependencies: `npm install`
4. Start MongoDB locally
5. Run server: `node server.js`
6. Open frontend/tasks.html in a browser

## Features Completed
- Navbar, Login page, Dashboard, Profile card, Responsive sidebar
- Task Manager with Add/View/Delete functionality
- REST APIs (GET, POST, DELETE) connected to MongoDB
