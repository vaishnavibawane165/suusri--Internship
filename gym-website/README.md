# PowerFit Gym Website

## Industry
Gym / Fitness

## Objective
A modern, responsive, animated gym website built as part of the Week 2 SuuSri AI internship task.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
- GSAP + ScrollTrigger

## Features
- Responsive navbar with mobile hamburger menu
- Hero section with GSAP entrance animation
- Scroll-triggered section reveal animations (GSAP ScrollTrigger)
- Programs, Trainers, Membership Plans, Facilities sections
- Testimonials section
- Class schedule table
- FAQ accordion (click to expand/collapse)
- Contact form

## GSAP Animations Used
- Hero heading, subtext, and button fade/slide-in on page load
- Scroll-triggered fade + slide-up animation for every section

## How to Run
Open `index.html` in any browser.
